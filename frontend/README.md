# DangoKiller 프론트엔드

당고킬러 서비스의 화면을 만드는 저장소입니다. 백엔드와 DB는 [AH_06_02](https://github.com/AI-HealthCare-06/AH_06_02)에 있습니다.

## 레포 두 개를 쓰는 이유

| 저장소 | 담당 범위 |
| --- | --- |
| AI-HealthCare-06/AH_06_02 | FastAPI 백엔드, MySQL, 마이그레이션, AI 워커, 기획 문서 원본 |
| subin-1122/DangoKiller | React 프론트엔드 |

명세서와 요구사항의 원본은 구글 시트이고, 백엔드 저장소의 `docs/`에 마크다운 사본이 있습니다. 이 저장소에는 화면을 만드는 데 필요한 것만 복사해 둡니다. 복사본 맨 위에 언제 뽑았는지 적혀 있으니, 날짜가 오래됐으면 백엔드 저장소에서 다시 가져옵니다.

## 시작하기

```bash
npm install
npm run dev
```

백엔드를 함께 띄우려면 AH_06_02 저장소에서 `docker compose up -d`를 먼저 실행합니다. API는 `http://localhost:8000/api/v1`입니다.

## 폴더

```
src/           화면과 컴포넌트
public/        글꼴, 이미지, 영상
docs/
  api-spec.md  API 명세 사본
  design.md    화면 설계 사본
  prototype/   당고킬러-모험시안_v2.html (단일 파일 시안)
```

## 디자인 시안

docs/prototype/당고킬러-모험시안_v4.html을 브라우저로 열면 전체 흐름을 볼 수 있습니다. 서버 없이 파일만 열면 됩니다. 11화면이고, 글자와 입력창과 게이지가 전부 실제 HTML과 CSS라 마크업을 그대로 가져다 쓸 수 있습니다.

시안을 만든 사람은 최병주이고, 생활습관과 검진정보 화면, 도감 상태 표시는 배수빈이 더했습니다.

## 글꼴

제목은 Black Han Sans, 본문은 Pretendard를 씁니다. 둘 다 SIL Open Font License입니다. 글꼴 파일을 `public/fonts/`에 둘 때 라이선스 전문도 같은 폴더에 함께 둡니다. 번들로 배포하는 이상 각 사본에 저작권 고지와 라이선스를 넣어야 합니다.

## 이 저장소에 두지 않는 것

백엔드 코드, 마이그레이션, 모델 학습 코드, 국민건강영양조사 원시자료. 원시자료는 보안서약 대상이라 어떤 공개 저장소에도 올리지 않습니다.
