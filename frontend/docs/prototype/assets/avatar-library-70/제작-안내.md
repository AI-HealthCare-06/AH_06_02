# 모험가 꾸미기 70종

내장 ImageGen으로 제작하는 투명 배경 이미지 라이브러리입니다.

- 머리: 같은 얼굴에 사용할 헤어스타일 10종
- 모자: 10종
- 상의: 10종
- 하의: 10종
- 가방: 10종
- 손 아이템: 10종
- 신발: 신발 한 쌍을 한 이미지로 하여 10종

각 WebP와 같은 이름의 JSON에 디자인 이름과 생성 프롬프트가 있습니다. 전체 후보는 v5 가방 화면에서 비교하며, 개인 PC의 출력 경로는 제외했습니다. 이미지는 제공받은 PNG에서 무손실 변환했습니다.

이미지는 기존 모험가의 그림체를 맞춘 독립 장비입니다. 실제 캐릭터에 겹쳐 사용할 때는 장비마다 크기와 부착 위치를 조정해야 합니다. 이 제작 단계에서는 HTML 보상 풀을 변경하지 않습니다.
