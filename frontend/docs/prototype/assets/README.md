# v5 시안 자산

사용자가 제공한 v5의 모험가·장비·캐릭터 변화·마을 지도·방 가구·꾸미기 후보 자산이다. 생성 기록과 프롬프트는 함께 보존하며, 개인 PC에서만 유효한 출력 경로는 제거했다.

- `avatar-library-70/`: 머리·모자·상의·하의·가방·손 아이템·신발의 후보 각 10종. 개별 JSON에 이름과 원래 생성 프롬프트가 있다. 후보 모두가 실제 보상이나 장착 기능으로 구현됐다는 뜻은 아니다.
- `room-decor-v1/`: 방 배경·기본 및 보상 가구·소품. `catalog.json`은 이 폴더의 파일을 가리킨다.
- `v5-reference-*`: 제공 HTML에 내장돼 있던 이미지·영상 중 기존 v4 자산과 일치하지 않는 파일.
- 나머지 WebP: 모험가 기본·전투 모습, 장비, 단계별 캐릭터와 마을 지도.

원래 PNG 이미지는 보이는 픽셀과 투명도를 유지하는 무손실 WebP로 변환했다. 기존 v4와 동일한 이미지·폰트는 복제하지 않고 `frontend/d/assets/`를 참조한다. ZIP·`.DS_Store`·변환 전 파일 크기 기준의 품질 보고서는 포함하지 않는다.

원래 생성 프롬프트는 원문을 유지한다. 이 폴더의 시각 표현·획득량·희귀도는 팀 합의 전 제안이며, 건강 위험도나 임상적 판단의 근거로 사용하지 않는다.
