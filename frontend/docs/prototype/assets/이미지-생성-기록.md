# 단계별 캐릭터 이미지

내장 이미지 생성 도구로 사용자의 첫 참고 이미지를 참조해 생성했다.
파일: `evolution-sprites.webp` · 5열 × 4행 · 투명 배경

## 생성 지시

첫 사용자가 첨부한 검은 배경의 4행 5열 몬스터 진화 이미지가 유일한 디자인 기준이다. 웹페이지 스크린샷은 무시한다. 원본과 최대한 동일한 캐릭터 디자인, 포즈, 단계별 형태, 표정과 재질을 표현한다. 투명 배경에 정확히 5열×4행 균등 셀, 각 셀 한 캐릭터 중앙 배치, 온전한 전신, 넉넉한 여백, 글자·번호·제목·구분선 없음.

- 스파이크: 작은 노랑 결정 가시 생물 → 단순 노랑 세포 → 돌이 섞인 노랑 가시 생물 → 회색 암석으로 덮인 결정 구체 → 회색 암석과 금빛 결정 덩어리.
- 알데: 작은 연보라 토끼 → 술잔 옆 보라 토끼 → 녹색 반점과 처진 표정 → 귀가 해지고 구멍난 회녹색 토끼 → 긴 귀와 해골 얼굴의 창백한 토끼가 병을 든 모습.
- 코티니: 옅은 회색 뭉게 연기 → 회색 소용돌이 → 크고 깊어진 연기 → 짙은 회색 사나운 연기 → 촘촘한 검정 연기와 강렬한 눈.
- 비세라: 통통한 빨간 작은 뿔 악마 → 반점과 지친 눈 → 늘어진 살과 주름 → 창백하고 쭈글한 악마 → 길고 가는 팔과 해골 얼굴.

각 단계의 실루엣과 얼굴이 확실히 변해야 한다. 색상 필터만 바꾸는 것은 금지한다. 원본과 같은 부드러운 입체 클레이·장난감 재질이며 유혈은 표현하지 않는다.
