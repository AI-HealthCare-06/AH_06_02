# 모델 입력과 KNHANES 응답 코드 대응

최종 점검: 2026-10-01. KNHANES 제9기 2022~2024 공통 원 변수를 canonical 서비스 입력으로 변환한다. 원시 코드북에는 원문항 선택지를 유지하고, API·테이블의 저장값은 아래 canonical 값을 사용한다. 제품 요구사항의 사용자 질문 기간은 최근 4주지만 KNHANES 음주·식생활 문항은 최근 1년, 활동 문항은 최근 1주/평소다. 동일한 빈도 구간으로 근사할 뿐 관찰기간이 동일하다고 해석하지 않는다. 원시 파일 및 사람별 결과는 로컬 `data/`에 두고 커밋하지 않는다. [질병관리청 KNHANES 원시자료·이용지침서](https://knhanes.kdca.go.kr/knhanes/main.do).

| 서비스 입력 | 설문 선택지/원시 코드 | canonical 모델 값 | 비고 |
|---|---|---|---|
| `age` | 원 만 나이 | 정수, 19 이상 | 성인 모집단 |
| `sex` | `sex`: 1 남성, 2 여성 | `M`, `F` | 모델 입력 코드로 전달하지 않음 |
| `bmi` | `HE_BMI` | kg/m² 실수 | 앱에서는 키·체중으로 계산 가능 |
| `waist_cm` | `HE_wc` | cm 실수 | 양수만 유효 |
| `smoking_current` | `sm_presnt`: 0 아니오, 1 예 | 0 또는 1 | 현재흡연 파생 지표 |
| `alcohol_frequency` | `BD1_11`: 1 최근 1년간 안 마심; 2 월 1회 미만; 3 월 1회 정도; 4 월 2~4회; 5 주 2~3회; 6 주 4회 이상 | 해당 코드 1~6을 범주형으로 보존 | `BD1_11=8`은 평생 음주 경험 없음이 확인된 경우 1로 변환; 9는 결측 |
| `alcohol_amount` | `BD2_1`: 1 1~2잔; 2 3~4잔; 3 5~6잔; 4 7~9잔; 5 10잔 이상 | 해당 코드 1~5 범주; 최근 1년 비음주(빈도 1)에 동반된 코드 8만 0 | 코드 9·불명확한 비해당은 결측; 10잔 이상 구간은 정확한 잔 수를 뜻하지 않음 |
| `walking_days` | `BE3_31`: 1 전혀 안 함; 2~8 주 1~7일 | 원시 코드에서 1을 뺀 0~7일/주 | 88·99는 우선 결측, 유효한 0일이면 걷기 분도 0 |
| `walking_minutes` | `BE3_32` 시간 + `BE3_33` 분, 1회 걷기 | `hour × 60 + minute` | 88·99·범위 오류는 결측; 0~1440분 |
| `strength_days` | 서비스 입력은 0~7일/주; KNHANES `BE5_1`: 1 전혀 안 함; 2~5 주 1~4일; 6 주 5일 이상 | 모델 입력은 `min(service_value, 5)`; 원시 코드는 1을 뺀 0~5 | 서비스가 6·7일을 받더라도 학습 자료는 5일 이상을 세분하지 않으므로 5로 묶음 |
| `sitting_minutes` | `BE8_1` 시간 + `BE8_2` 분 | `hour × 60 + minute`, 0~1440 | `sedentary_time_high`의 별도 feature; SHAP을 걷기와 합치지 않음 |
| `dining_out_freq` | `L_OUT_FQ`: 1 하루 2회 이상; 2 하루 1회; 3 주 5~6회; 4 주 3~4회; 5 주 1~2회; 6 월 1~3회; 7 월 1회 미만 | 원시 코드 1~7 범주형 | sodium_behavior 실험 후보; 9는 결측 |
| `family_history_dm` | `HE_DMfh1~3`: 부모·형제자매 중 하나라도 1이면 있음, 유효한 응답이 모두 0이면 없음 | 1 또는 0 | 형제자매 코드 8은 외동이므로 0; 남은 unknown은 결측 |
| `family_history_htn` | `HE_HPfh1~3`, 같은 집계 규칙 | 1 또는 0 | 동일 |

화면의 응답 라벨은 서비스 선택지에서 canonical 값으로 매핑한다. 예를 들어 “주 2~3회” 음주 선택은 `alcohol_frequency=5`, 걷기 “주 3일”은 `walking_days=3`이다. 술의 10잔 이상 범주를 정확한 섭취 잔 수로 오해하지 않는다. 음주·외식 입력은 4주를 묻고 학습 코드는 1년 문항에서 왔으므로 빈도 category를 옮기는 근사이며, 기한 불일치는 성능·해석 한계로 남긴다.

## 정답 누수 차단

| 학습 대상 | 라벨 | X에서 제외 |
|---|---|---|
| 당뇨 | `HE_DM_HbA1c`: 3 양성, 1·2 음성 | 공복 혈당, HbA1c, 혈당 검사·진단·인슐린·당뇨약 변수 |
| 고혈압 | `HE_HP`: 4 양성, 1~3 음성 | 수축기·이완기 혈압, 진단·혈압약 변수 |

라벨 생성에 사용되는 측정치·진단·치료 정보를 X에서 다시 사용하지 않는다. 서비스는 질환별 진단·복약 상태를 따로 판정하며 한 질환의 기존 진단이 다른 질환 예측을 막지 않게 한다.

원 변수·연도별 유효 코드와 특수값은 [`preprocess_knhanes.py`](../../scripts/model/preprocess_knhanes.py)에서 엄격하게 검사한다. 잘 모르는 코드를 정상값으로 바꾸지 않고 전처리를 실패시킨다.
