# 데이터 준비 규칙

KNHANES 제9기(2022~2024)의 HN22_ALL.sav/HN23_ALL.sav/HN24_ALL.sav를 사용한다. 공유 폴더에 있던 연도별 ZIP과 `codebook.xlsx`를 로컬 `data/raw/`에서 확인했다. 코드 정의는 KNHANES 제9기 원시자료 이용지침서와 원본 SPSS label/domain을 대조했다. 원시자료와 개인 단위 결과는 `.gitignore` 아래 `data/`에만 둔다. [질병관리청 KNHANES 원시자료·이용지침서](https://knhanes.kdca.go.kr/knhanes/main.do). 공유받은 파일 이용조건은 제출 전 팀이 다시 확인한다.

## 전처리 규칙 (`knhanes-ix-v1`)

- 표본은 성인 만 19세 이상. 연도별 SPSS 표본 수와 ID 중복을 검사한다.
- sex 1→M, 2→F. sm_presnt 0/1은 KNHANES 현재흡연 파생 지표를 그대로 쓴다.
- age, HE_BMI, HE_wc는 각각 만 나이, BMI(kg/m²), 허리둘레(cm)로 가져온다. 비양수 신체측정값은 결측 처리한다.
- BD1_11은 1~6 범주형. 평생 음주 경험 없음(BD1=1)으로 인해 BD1_11=8인 경우 ‘최근 1년간 음주 없음’ 범주 1로 매핑한다. 최근 1년 무음주(코드1)는 그대로 유효하다. BD2_1은 1~5 범주형이며 최근 1년 무음주·문항 비해당 코드8은 값 0으로 표현한다. 모름 9는 결측이다. 2022~2024 성인 원자료의 BD1_11=8 응답 1,856건은 모두 BD1=1·BD2_1=8이므로 `alcohol_frequency=1`, `alcohol_amount=0`으로 매핑된다.
- BE3_31 코드 1~8은 ‘전혀 안 함’~‘주 7일’이므로 1을 빼 0~7일로 변환한다. 걷기 시간은 BE3_32×60+BE3_33 분/회. 시간 88·99는 우선 결측 처리하고, BE3_31=1로 0일이 확인된 경우에만 걷기 시간을 0으로 둔다. BE3_31=99(모름)는 일수 결측이며 0으로 간주하지 않는다. 성인 원자료에서 BE3_32·BE3_33의 88 각 2,291건은 BE3_31=1과 일치한다. BE3_31=99는 1,508건이고 시간 변수의 99는 각 1,532건으로 결측 처리된다.
- BE5_1 코드1~6에서 1을 빼 0·1·2·3·4·5로 둔다. 원자료의 코드6은 ‘주 5일 이상’이므로 5는 정확한 횟수가 아닌 하한값이다.
- BE8_1·BE8_2는 하루 좌식·누운 시간의 시간·분. 코드88·99를 먼저 결측으로 처리하고 합산해 분/일로 만든다. 유효 구간은 0~1440분, 분 보조값은 0~59다.
- L_OUT_FQ 코드1~7은 범주 순서 그대로 보존한다(하루 2회 이상부터 월 1회 미만까지). 9는 모름·무응답으로 결측 처리한다. 소디 후보는 외식 빈도 proxy로만 쓰며 나트륨 g/mg 값으로 변환하지 않는다.
- LS_VEG2 코드1~9는 김치·장아찌를 제외한 최근 1년 채소·버섯·해조류 섭취 빈도 범주다(1 하루 3회 이상, 9 월 1회 미만). 코드 99는 모름·무응답으로 결측 처리한다. `vegetable_frequency`는 순서형 범주로 처리하고, 별도 `vegetable_intake_low` 후보에 연결한다. 이 값은 섭취량/그램이 아니며 외식·소디 factor 계산에 쓰지 않는다.
- 가족력은 직계가족·형제자매 중 한 명이라도 코드1이면 1, 전부 유효한 0이면 0, 나머지는 결측. 형제자매 코드8은 외동이므로 0으로 취급한다.
- 당뇨 학습 eligibility는 DE1_dg=0, DE1_31·DE1_32가 각각 0 또는 8인 성인이다. 고혈압 eligibility는 DI1_dg=0, DI1_2가 5(복용 안 함) 또는 8(진단 이력 없음 비해당)인 성인이다. 알 수 없는 9는 제외한다. 질환별로 독립 적용한다.
- 당뇨 HE_DM_HbA1c는 비임신·8시간 이상 공복 검사 대상으로 생성된 유효 코드만 쓴다. 이 파일은 해당 원시 생성 라벨을 그대로 쓰며 공복 혈당·HbA1c 원값, 혈압, 진단·약물 정보는 X에 넣지 않는다. y의 기준 구성요소로 쓰인 검사값이 X에도 들어가는 누수를 막는다.

코드 8·9·88·99를 무조건 같은 뜻으로 바꾸지 않는다. 문항별 분기와 공식 라벨을 따라 특수코드를 해석하고, 나이 99·좌식 8시간 같은 정상값은 보존한다.

## canonical CSV

원시자료를 바로 모델에 넣지 않고 단위와 코드를 검증한 CSV를 생성한다. core 열은 model.md의 첫 12개 feature다. 외식 빈도 `dining_out_freq`, 좌식 `sitting_minutes`, 채소 `vegetable_frequency`는 ablation 후보 열이다. 부가 열은 `survey_year`, `HE_DM_HbA1c`, `HE_HP`다. 한 사람 한 조사연도 한 행으로 중복 ID 검사 후 내보낸다. ID는 학습 feature가 아니다.

서비스 열의 alcohol_frequency/alcohol_amount는 공식 코드 의미를 범주로 인코딩한다. 기본 모델은 범주형으로 처리하여 코드 차이를 실제 잔 수 차이라고 해석하지 않는다. 가족력 unknown, 유효한 비해당·비음주 상태, 실제 누락을 구별한다. 필수 입력 누락 서비스 요청은 거절하며 학습 결측 대치는 train에만 fit한다.

BMI는 키·몸무게에서 일관된 식으로 생성해 HE_BMI와 허용 오차 내 대조한다. 키·몸무게와 나이는 예측 시점 값으로 스냅샷에 저장해 프로필 수정이 과거 결과를 바꾸지 않게 한다.

## 분할과 누수 차단

- 2022 train, 2023 validation, 2024 final test로 먼저 분리한다.
- 인코딩·대치·모델 적합·SHAP background·global importance 원값은 train만 사용한다.
- 탐색 1회전의 `P95_reference`는 2022 train에서 추출한 256명 SHAP reference로 질환×factor×model_version별 계산한다. 이는 작은 표본의 탐색 추정치이며 최종 배포 calibration은 아니다. 최종 값은 승인할 학습 데이터 전체 또는 사전 합의한 충분한 training reference 집단으로 다시 계산하고 artifact metadata에 고정한다. 2024 final test는 calibration에 사용하지 않는다.
- 모델/feature 선택·분류 임계값은 validation만 사용한다. 최종 test는 선택된 모델에 대해서만 1회 평가한다.
- y가 없는 행은 질환별 학습·평가에서 제외한다. 누락을 음성으로 만들지 않는다.
- 모델의 threshold는 validation recall>=0.70인 후보 중 specificity 최대값으로 선택한다. 임의의 임상 기준으로 설명하지 않는다. 3단계 등급 두 경계는 성능 검토 후 별도 고정하며 현재 미산출이다.

가중치·층화·집락이 있는 표본이다. 단순 분류 실험의 비가중 지표를 대한민국 유병률로 보고하지 않는다. 인구 추론 또는 가중평가가 필요하면 적합한 조사 가중치와 설계를 별도 명시한다.

## 해석상 한계

- 단면자료라 미래 발병·개별 치료효과를 직접 학습하지 않는다.
- 서비스 문항은 최근 4주지만 학습 문항에는 1주·현재·1년 평균이 섞여 있다. 기간을 4주로 단순 곱셈해서 1년 자료로 만들지 않는다. 질문 의미와 응답 척도는 C 입력 문서와 함께 고정한다.
- 외식 빈도는 나트륨 proxy이며 요나트륨과의 상관 근거는 별개다. 팀 문서에서 보고된 상관·평균은 이번 작업에서 재계산하지 않았다.
- 현재 흡연 0/1은 개비 수 감소를 표현하지 못한다.
- 모든 수치표는 train/validation/test, 연도, 유효 표본 수, 양성 수를 함께 기록한다.
