# 데이터 준비 규칙

KNHANES 2022~2024 HN22_ALL.sav/HN23_ALL.sav/HN24_ALL.sav를 사용한다. 자료는 사용자 등록·이용 조건 확인이 필요한 자료이며 원시자료·개인 단위 전처리 결과는 공개 Git에 올리지 않는다. 출처: https://knhanes.kdca.go.kr/knhanes/rawDataDwnld/rawDataDwnld.do . 이용조건·코드북 원문은 아직 확보하지 못했으므로 라이선스명을 임의로 부여하지 않는다.

## 공식 코드북을 확인할 순서

1. 연도별 column label·자료분석 지침의 value code·단위를 대조한다. 3개년 같은 이름이 같은 의미인지 확인한다.
2. BE8_1의 단위와 분 보조변수 존재 여부를 확인한다. 시간이면 분으로 변환하되 특수코드를 먼저 처리한다. BE8_1 단독을 분으로 가정하지 않는다.
3. BE3_31~33의 걷기 일수·시간·분 역할, BE5_1의 일수/범주 역할을 확인한다.
4. BD1_11/BD2_1/sm_presnt/HE_*fh/L_OUT_FQ의 비해당·모름 코드를 변수별로 기록한다.
5. 임신 대상 제외 조건과 해당 변수의 코드, 연도별 유효 라벨을 확인한다. 자료에 없는 임신 상태를 건강한 상태라고 추정하지 않는다.

숫자 8·9·99를 모든 열에서 일괄 NaN으로 치환하지 않는다. 나이 99, 좌식 8시간 등 정상 값도 있을 수 있다. '전혀 안 함'이 유효한 0인지 '비해당'인지 원문 분기를 확인한다. 모름/무응답은 결측으로 처리한다. 가족력은 가족 구성원 중 한 명이라도 '있음'이면 1, 전부 유효한 '없음'이면 0, 나머지는 unknown이다. 가족이 없음을 질환 없음으로 치환할지도 코드북 근거로 정한다.

## canonical CSV

원시자료를 바로 모델에 넣지 않고 단위와 코드를 검증한 CSV를 생성한다. 열 목록은 model.md와 같다. 부가 열은 `survey_year`, `HE_DM_HbA1c`, `HE_HP`다. 후보 채소 열은 `vegetable_frequency`이며 실제 의미·단위 확인 후만 사용한다. 한 사람 한 조사연도 한 행으로 중복 ID 검사 후 내보낸다. ID는 학습 feature가 아니다.

서비스 열의 alcohol_frequency/alcohol_amount는 공식 코드 의미를 범주로 인코딩한다. 기본 모델은 범주형으로 처리하여 코드 차이를 실제 잔 수 차이라고 해석하지 않는다. 가족력 unknown, 유효한 비해당·비음주 상태, 실제 누락을 구별한다. 필수 입력 누락 서비스 요청은 거절하며 학습 결측 대치는 train에만 fit한다.

BMI는 키·몸무게에서 일관된 식으로 생성해 HE_BMI와 허용 오차 내 대조한다. 키·몸무게와 나이는 예측 시점 값으로 스냅샷에 저장해 프로필 수정이 과거 결과를 바꾸지 않게 한다.

## 분할과 누수 차단

- 2022 train, 2023 validation, 2024 final test로 먼저 분리한다.
- 인코딩·대치·SHAP background·HP scale·global importance는 train만 사용한다.
- 모델/feature 선택·분류 임계값은 validation만 사용한다. 최종 test는 선택된 모델에 대해서만 1회 평가한다.
- y가 없는 행은 질환별 학습·평가에서 제외한다. 누락을 음성으로 만들지 않는다.
- 모델의 threshold는 validation recall>=0.70인 후보 중 specificity 최대값으로 선택한다. 임의의 임상 기준으로 설명하지 않는다. 3단계 등급 두 경계는 성능 검토 후 별도 고정하며 현재 미산출이다.

가중치·층화·집락이 있는 표본이다. 단순 분류 실험의 비가중 지표를 대한민국 유병률로 보고하지 않는다. 인구 추론 또는 가중평가가 필요하면 적합한 조사 가중치와 설계를 별도 명시한다.

## 해석상 한계

- 단면자료라 미래 발병·개별 치료효과를 직접 학습하지 않는다.
- 서비스 문항은 최근 4주지만 학습 문항에는 1주·현재·1년 평균이 섞여 있다. 기간을 4주로 단순 곱셈해서 1년 자료로 만들지 않는다. 질문 의미와 응답 척도는 C 입력 문서와 함께 고정한다.
- 외식 빈도는 나트륨 proxy이며 요나트륨과의 상관 근거는 별개다. 팀 문서에서 보고된 상관·평균은 이번 작업에서 재계산하지 않았다.
- 현재 흡연 0/1은 개비 수 감소를 표현하지 못한다.
- 모든 수치표는 train/validation/test, 연도, 유효 표본 수, 양성 수를 함께 기록한다.

## 데이터 인수 기록

현재 원시 .sav 3개와 공식 변수설명서 미확보. 변환 규칙·성능 수치·모델 배포 artifact 확정은 해당 파일을 확보한 뒤 진행한다. 문서에 기록된 17,262명 등은 기존 기획서의 보고값이며 이번 실행 결과가 아니다.
